# Что внутри айсберга? — материалы для прессы

Приключение от первого лица для Android: свободно плавьте лёд, прокладывайте свой путь в глубину айсберга, находите ресурсы и улучшайте снаряжение.

**[Скачать все материалы одним архивом](https://github.com/kupryian/iceberg-press-kit-ru/archive/refs/heads/main.zip)**

В комплекте — 13 скриншотов, русский трейлер, обложка с мамонтом и подготовленные автором тексты.
